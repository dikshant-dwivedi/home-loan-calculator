## Code Standards (When Coding Begins)
- TypeScript strict mode ALWAYS enabled
- Write tests for ALL calculation logic (100% coverage required)
- Write tests for UI components (70%+ coverage required)
- Use Decimal.js for all money/percentage calculations (no native JS numbers)
- Commit after each working feature with conventional commit messages
- Follow Indian locale: ₹ symbol, lakhs/crores format, DD/MM/YYYY dates

## Calculation Accuracy
- EMI calculations must match bank calculators exactly
- Use reducing balance method with monthly compounding
- Round to nearest rupee (integer) for display
- Use Decimal.js internally for precision
- Validate against test cases in 03-CALCULATION-FORMULAS-REFERENCE.md

## Indian Loan Specifics
- Interest rates: 0.01% to 30% annual
- Loan amounts: ₹1,00,000 to ₹10,00,00,000
- Tenure: 6 months to 40 years (480 months)
- Monthly compounding (not daily/quarterly)
- No tax calculations in Phase 1
- No floating rate changes in Phase 1

## PROJECT-STATE.md Auto-Trim Rules (CRITICAL)
**When updating PROJECT-STATE.md, ALWAYS check and auto-trim:**

1. **Count entries:**
   - "What's Complete" section: count ✅ bullet points
   - "Recent Decisions/Changes" section: count decision entries
   - Total = sum of both sections

2. **If total > 60 entries:**
   - Keep ONLY 40 newest entries in "What's Complete"
   - Keep ONLY 20 newest entries in "Recent Decisions/Changes"
   - Move older completions to "Major Milestones" section as single-line bullets with dates
   - Delete older decisions entirely (they're in git history)
   - Inform user: "Trimmed PROJECT-STATE.md: archived [N] old entries to milestones"

3. **Major Milestones format:**
   ```markdown
   ## Major Milestones (All-Time)
   - ✅ Dec 2025: Documentation complete, project setup
   - ✅ Jan 2026: Backend API v1 (15 features completed, see commits abc-xyz)
   - ✅ Feb 2026: Frontend MVP deployed
   ```

4. **Rolling window principle:**
   - PROJECT-STATE.md = last 60 entries (roughly 30-60 days)
   - Git history = long-term archive
   - Always maintain this structure automatically

5. **DO NOT ask user permission to trim - just do it and inform**
